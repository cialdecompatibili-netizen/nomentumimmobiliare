# Agenzia Immobiliare

> Repo creata vuota per occupare il nome. Il sito verra' realizzato in futuro.

## Scopo

Sito per un'agenzia immobiliare in stile RE/MAX: vetrina di immobili in vendita e affitto, con rete di agenti/agenzie.

## Idee / da fare

- Catalogo immobili (vendita/affitto) con filtri: zona, prezzo, tipo, mq, camere
- Scheda immobile con galleria, mappa, planimetria, richiesta visita
- Pagine agenti/agenzie (profilo, contatti, immobili in gestione)
- Pagina 'Vendi con noi' / valutazione immobile
- Admin per inserire/gestire annunci (logica cmspush/ecommercealfolio1)
- Multilingua, SEO locale per zona

## Stato

Solo repo, nessun codice.
